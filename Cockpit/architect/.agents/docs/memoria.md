# Guia de Memória

## Fontes de Verdade
1. **ai-memory (MCP)** - Handoff programático entre agentes
2. **Vault/ (markdown)** - Auditabilidade legível por humano

## Como Consultar
- `memory_query` - Busca por palavras-chave
- `memory_recent` - Páginas recentes
- `memory_briefing` - Resumo estruturado

## Como Salvar
- `memory_write_page` - Página durável
- `memory_handoff_begin` - Handoff para próxima sessão

## Regras
- Não salvar senhas ou dados sensíveis
- Usar formato ADR para decisões
- Vault/ para auditabilidade, MCP para handoff
